# MySkillsOrganizer

🌐 [English version](README.md)

> **Визуальное интерактивное древо вашего человеческого развития — не просто задачи, а человек, которым вы становитесь.**

MySkillsOrganizer — это веб-приложение, созданное для визуализации ваших целей, навыков и зависимостей между ними. Оно построено на основе принципа **HumanBuilding (HB)**: самый ценный продукт любой полезной работы — это не внешняя вещь, а вы сами, ваши знания, умения и человеческие качества, развитые в процессе.

## ✨ Возможности

- **Визуальный холст**: Интерактивная область на базе Fabric.js для организации целей и навыков.
- **Шаблоны**: Создание, управление и обмен готовыми шаблонами развития.
- **Импорт из JSON (Новое!)**: Генерация структурированного древа развития за 30 минут с помощью любой популярной LLM и его импорт в приложение одним кликом.
- **Зависимости**: Определение и визуализация сложных связей между различными целями.
- **Обновления в реальном времени**: Синхронизация данных через Supabase.
- **Мультиязычность**: Полная поддержка русского и английского языков (i18n).

## 🚀 Быстрый старт

### Требования

- Node.js (рекомендуется >= 16.0.0)
- npm (>= 8.0.0)
- Бесплатный аккаунт [Supabase](https://supabase.com)

### Установка

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/tyaa10/my-skills-organizer-supabase.git
   cd my-skills-organizer-supabase
   ```

2. **Установите зависимости**

   ```bash
   npm install
   ```

3. **Настройте Supabase**

   - Создайте новый проект на [supabase.com](https://supabase.com).
   - Перейдите в **Settings → API** и скопируйте `Project URL` и `anon public` key.
   - Создайте файл `.env` в корне проекта и добавьте:

     ```env
     VITE_SUPABASE_URL=https://your-project-id.supabase.co
     VITE_SUPABASE_ANON_KEY=ваш_ключ_здесь
     ```

   - Откройте **SQL Editor** в панели управления Supabase и выполните скрипт из файла `supabase-schema.sql` для создания всех необходимых таблиц и политик безопасности (RLS).
   - Подробные инструкции см. в [SUPABASE_SETUP.md](./SUPABASE_SETUP.md).

4. **Запустите сервер разработки**

   ```bash
   npm run dev
   ```

5. **Откройте браузер**

   Перейдите по адресу `http://localhost:3000` (или порт, указанный в терминале).

## 🗄️ Схема базы данных

Приложение использует PostgreSQL со следующими основными таблицами:

- `users` / `userdata` — Профили и метаданные пользователей
- `nodes` — Узлы навыков/целей
- `templates` — Переиспользуемые шаблоны
- `template_nodes` — Узлы внутри шаблонов
- `dependencies` — Связи между узлами
- `template_dependencies` — Связи внутри шаблонов
